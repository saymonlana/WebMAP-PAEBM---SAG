Sistema de Coleta de Dados em Campo

Plano de implementação para WebMap PAEBM — Santo Antônio do Grama — MG

1. Visão Geral do Sistema

Três componentes que trabalham juntos:

COLETA EM CAMPO
Técnico com celular (offline)
• Marca ponto no mapa
• Preenche formulário
• Tira foto
▼ SINCRONIZAÇÃO
Quando o celular pegar internet, envia os dados
▼ TEMPO REAL
WebMap atualiza automaticamente
Gerente acompanha em tempo real
  • Offline: O técnico coleta o dia inteiro sem internet. Dados ficam salvos no celular.
  • Sincronização: Quando o celular pegar sinal (4G, Wi-Fi), envia tudo automaticamente.
  • Tempo real: Assim que chega no servidor, aparece no WebMap na hora. Não precisa recarregar a página.

2. O que o Servidor Precisa Ter

ComponenteO que fazOpcões
Banco de dadosGuarda as coletas, usuários, projetos, fotosPocketBase (SQLite), PostgreSQL
APIPonte entre o celular e o banco de dadosPocketBase (já inclui API pronta)
Armazenamento de fotosGuarda as imagens tiradas no campoPocketBase, disco local, S3
ⓘ Recomendação: PocketBase é um único arquivo .exe que faz tudo (banco + API + arquivos). Não precisa instalar nada.

4. App de Coleta (PWA)

O aplicativo que roda no celular do técnico em campo.

4.1 Funcionalidades

  • Login com email e senha (cada técnico tem seu próprio login)
  • Escolher projeto (PAEBM SAG, barragem X, etc.)
  • Mapa com fundo Google Satellite, funcional mesmo offline
  • Adicionar ponto — toca no mapa e marca a localização
  • Formulário configurável por projeto (perguntas diferentes para cada tipo de coleta)
  • Foto — tira foto pela câmera do celular e anexa ao ponto
  • Salvar offline — dados ficam seguros no celular mesmo sem sinal
  • Sincronizar — quando conectar à internet, envia tudo automaticamente
  • Histórico — visualizar todas as coletas do dia

4.2 Como instala no celular

  1. Abre o link no Chrome ou Edge do celular
  2. O navegador pergunta: "Adicionar à tela inicial"
  3. Pronto — vira um ícone na tela do celular como qualquer aplicativo
  4. Funciona igual um app da loja, mas sem precisar instalar pela Play Store

5. WebMap (já existente)

O WebMap atual (https://web-map-paebm-sag.vercel.app) será adaptado para:

  • Além dos dados históricos, mostrar as coletas em andamento
  • Atualizar automaticamente quando novos dados chegam

  • Exportar dados coletados em Excel, Shapefile e KML
  • Acessível de qualquer computador ou celular

6. Múltiplos Projetos e Pessoas

O sistema foi planejado para crescer.

6.1 Vários projetos

Cada projeto vira uma "collection" no banco. Você cadastra:

  • PAEBM Santo Antônio do Grama
  • PAEBM Outra Barragem
  • Levantamento de Nascentes
  • Cadastro de Propriedades
  • Qualquer outro levantamento de campo

Cada projeto tem seu próprio formulário (perguntas diferentes).

6.2 Várias pessoas coletando

  • Cada coletor tem login único (email + senha)
  • Você controla quem acessa o quê:
    • Fulano: coleta só do Projeto A
    • Ciclano: coleta de todos os projetos
    • Gerente: só visualização no WebMap
  • Dados ficam centralizados — ninguém perde planilha
  • WebMap mostra tudo em tempo real, filtrado por projeto ou coletor

7. Cronograma de Implementação

Fase 1 — Prova de Conceito (1 semana)

  • Montar servidor PocketBase no escritório (qualquer PC)
  • Criar app de coleta simples com um projeto piloto
  • Testar coleta no celular com um técnico
  • Ver dados aparecendo no WebMap

Fase 2 — Expansão (2 semanas)

  • Configurar acesso remoto (No-IP + roteador)
  • Criar cadastro de projetos e usuários
  • Testar com múltiplos técnicos simultaneamente
  • Ajustar formulários por projeto

Fase 3 — Produção (1 semana)

  • Escolher opção de servidor definitiva
  • Treinar equipe de campo
  • Iniciar uso real
